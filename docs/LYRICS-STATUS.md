# 全库歌词核验（v1.0.7）

本轮覆盖全部340个音频版本（约23.34小时）：建立录音指纹、检索对应歌本、进行波形比较或全长识别辅助定位，并完成全库文字读校。原始识别未直接用作发布歌词。检查完成不代表每个版本已达到逐句精确验收。

- 192个版本找到同录音波形证据：8处窗口验证并测量剪辑偏移和速度差。其中174个采用对应正式LRC，其余无可用正式LRC的版本继续使用音频定位。
- 2个版本保留经过原平台ID验证的歌词；3个版本为已确认或原文件明确标注的纯音乐，清除人声歌词。
- 159个版本采用歌本配合全长逐词定位，仍标记待复核；另2个版本（016.mp3、073-我.mp3）没有可靠人声定位，疑似器乐，未强行填词或断定。
- 本次337份歌词数据有修订，含错配歌词、外语版本、错字、制作信息、重复段落、前间奏和时间轴。共约1.09万个同步句段；句段/字数不是完整率。
- **仍有161个版本需要逐句音频验收，不能声称全库“绝不少词、全部精准”。** 公开LRC也可能存在错误，波形相同仅证明录音对应，不等于人工确认每个时间戳。未确认片段保留标记，不用拉伸时间来填补缺口。

重点修订：235-.mp3原来配《你是我神》，实为《我在这里敬拜》，已用同录音正式歌词替换并改标题；两首韩文录音改用韩文歌本；093钢琴版、260纯音乐移除人声词；145分段替换标记1/2/3按实际段落展开。《和散那》补查教会公开歌本译词，部分时间仍待确认。中文、英文、韩文、日文、德文及少数民族文字保留对应版本，未把译词当原唱词。

校订证据与逐首结果：`lyric-audio-review/full-library-report.json`。原始录音不修改，收藏歌单不受影响。本机手工歌词仍优先，旧偏移通过时间轴版本隔离。网页歌词网络优先，APK内置同一份新数据；APK不包含音频和识别模型。

验证：全库340条记录与时间边界、显示字符、纯音乐数据校验；36项Node测试；网页生产构建和Android APK构建。此次没有新增手机锁屏真机验收，不能用歌词数据测试替代设备实测。
