# 歌词校订状态（v1.0.5）

已检查340个音频文件的时长与解码片段指纹。20个重点异常版本重新进行本地识别与边界定位，识别稿只用于辅助检查，不直接发布。

《你们要赞美耶和华》欢快版与281版本是同一完整PCM录音，已采用正式逐句歌词；与正式试听录音的四处波形比对证明本地剪掉34.1755秒前奏，时间轴据此平移，含口白和重复段落。《哈利路！主我神作王了》039版本与正式录音四处波形一致、无时间差，已采用正式LRC。另两首从音频内嵌原平台ID取得歌词，并确认时长匹配。Dongye《Walking with HIM》中的025钢琴版标为纯音乐，无人声歌词。

- 当前接受6735个同步片段，源片段12864个；分句粒度不同，不能当作人工听校比例。
- 182个版本的片段匹配覆盖不足60%；18个版本暂无可靠同步片段。全库“不少词、全部精准”尚未完成。
- 缺口停止上一句高亮，不伪造时间轴；部分未观测的结束位置使用保守上限并标记endEstimated。
- 网页和APK只包含当前歌词；原始识别、旧LRC保存在审计目录。网络优先获取新歌词，断网使用缓存；旧远程版本不得覆盖新版内置歌词。录音时间轴改变时隔离旧偏移，本机手工修改保持优先。

桌面Chrome实测点击当前歌曲进入中央歌词、歌词跳转、播放暂停、Esc和返回焦点。安卓API34实测屏幕关闭后媒体会话歌词与进度继续更新，并实际显示于系统锁屏卡片；这是一句随播放更换的歌词，不是锁屏上的多行歌词列表。手机Chrome锁屏尚未进行设备实测。

27项Node测试覆盖版本映射、分句、重复、缺口、偏移、正式来源、纯音乐、最新歌词缓存及网页媒体元数据。全库仍有缺漏，不能宣称逐首完整校对完成。
